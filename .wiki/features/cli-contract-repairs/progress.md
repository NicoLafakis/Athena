## Release verification

The final candidate must pass `pnpm typecheck`, `pnpm lint`, `pnpm test`, and
`pnpm build` sequentially on its exact staged tree. Run `python .longhaul/verify.py`
from the repository root; its ignored `.longhaul/evidence.json` and `EVIDENCE.md`
are generated by executed commands, not manually authored pass claims. This Codex
session runs the verifier explicitly; no global harness hook is installed.
The checked tree ID, commit, PR and final six-job CI results are recorded in the
release handoff. All criteria remain subject to that final gate.

## Boundaries

Real terminal/human NVDA/Narrator acceptance and live-provider behavior were not
exercised. Revision rechecks are not filesystem transactions; redaction recognizes
credential patterns, not every possible private value. Output inspection exposes
retained content and omissions, not producer-discarded bytes. Deep recovery,
whole-task accounting and cross-machine synchronization remain outside this release.
